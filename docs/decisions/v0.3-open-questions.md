## Resolved in v0.3

### get_write_log tool ✅
Built. Reads `~/.nowlink/logs/writes-YYYY-MM-DD.log` with date/table/record filters.

### Mandatory field detection breaks on custom tables ✅
Resolved. `TABLE_MANDATORY` replaced by dynamic `get_table_ancestry()` +
`get_mandatory_fields()`. Works for any table on any instance.
Full history in `docs/decisions/v0.3-known-issues.md`.

### Session token design ✅
In-memory dict `_bulk_tokens`. UUID → stored state. 5-min TTL.
`confirmed` parameter removed from `bulk_execute` — two-turn UX via tool descriptions.

### Hard limit: 500 records ✅
Enforced in both `bulk_preview` (refuses to generate token) and `bulk_execute`
(re-counts before firing, refuses if > 500).

### Rate limiting / batch execution approach ✅
Resolved via batch API in chunks of 50. Sub-request statuses ignored entirely.
Post-execute re-count is source of truth. See session notes for full journey.

### Failure handling in bulk_execute ✅
Post-execute re-count reports `remaining` records still matching the filter.
User re-runs if remaining > 0. No per-record failure tracking needed.

### Seed script ✅ (skipped)
PDI already had sufficient test data. Seed script not needed for proof of concept.
