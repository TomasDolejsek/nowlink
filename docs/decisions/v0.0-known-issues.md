# v0.0 — Known Issues

## verify=False on all httpx calls

**Symptom:** SSL certificate verification is disabled on every HTTP call.

**Root cause:** PDI uses certificates that httpx cannot verify on Windows. `certifi` was
already installed but didn't resolve it. `verify=False` was added as a quick fix.

**Impact:** Insecure — not acceptable to ship to PyPI.

**Fix planned (v0.3):** Add a `NOWLINK_SSL_VERIFY` option to `.env` defaulting to `true`,
with a `--no-verify` flag for `nowlink init` that sets it to `false` for PDI use.

---

## Hardcoded venv path in `nowlink connect` ✅ Fixed in v0.1

**Fix:** Auto-detect the executable path using `sys.executable` — the nowlink
executable sits in the same `Scripts/` directory as the Python interpreter.

---

## No token refresh using refresh_token

**Symptom:** On token expiry, NowLink fetches a completely new token using username +
password instead of using the refresh_token from the previous response.

**Impact:** Minor — works correctly, just slightly less efficient. Full re-auth every
30 minutes instead of a lightweight refresh.

**Fix planned (v0.3):** Implement proper refresh_token flow.

---

## No logging ✅ Fixed in v0.1

**Fix:** Added `~/.nowlink/logs/YYYY-MM-DD.log` via `logger.py`.
