## Overview

v0.0 establishes the foundation: project structure, OAuth authentication, credential
storage, CLI entry points, and a working MCP server with a single `ping` tool that
confirms the connection to ServiceNow from Claude Desktop.

## CLI Commands

### `nowlink init`

Prompts for credentials, stores them securely, and tests the connection.

**Inputs (interactive prompts):**

| Prompt | Description | Stored in |
|--------|-------------|-----------|
| Instance URL | e.g. `https://dev123.service-now.com` | `.env` as `NOWLINK_INSTANCE_URL` |
| OAuth Client ID | From Application Registry | OS keychain |
| OAuth Client Secret | From Application Registry | OS keychain |
| Username | Integration user (e.g. `nowlink.dev`) | OS keychain |
| Password | Integration user password | OS keychain |

**Output (success):**
```
Testing connection...
✓ Connected successfully!
Instance: https://dev123.service-now.com

Run nowlink connect to configure Claude Desktop.
```

---

### `nowlink whoami`

Verifies stored credentials are working and shows the connected user.

**Output (success):**
```
✓ Connected
  Instance:  https://dev123.service-now.com
  User:      NowLink Dev (nowlink.dev)
```

---

### `nowlink connect`

Writes the NowLink MCP server configuration to Claude Desktop's config file.

**Config file location:**
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`
- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`

**Behaviour:** Reads existing config, merges NowLink entry, does not overwrite other MCP
servers. Auto-detects the venv executable path from `sys.executable` — does not hardcode.

**Config written:**
```json
{
  "mcpServers": {
    "nowlink": {
      "command": "C:\\path\\to\\.venv\\Scripts\\nowlink.exe",
      "args": ["serve"]
    }
  }
}
```

---

### `nowlink serve`

Starts the FastMCP server. Called by Claude Desktop automatically — not run manually.

## Module: `auth.py`

### Credential Storage

| Data | Storage | Key |
|------|---------|-----|
| Client ID | OS keychain | `nowlink / client_id` |
| Client Secret | OS keychain | `nowlink / client_secret` |
| Username | OS keychain | `nowlink / username` |
| Password | OS keychain | `nowlink / password` |
| OAuth token (JSON) | OS keychain | `nowlink / token` |
| Instance URL | `.env` | `NOWLINK_INSTANCE_URL` |
| Page size | `.env` | `NOWLINK_PAGE_SIZE` |

### Token Lifecycle

```
nowlink init
    └── save_credentials()      # Store in keychain + .env
    └── fetch_token()           # POST /oauth_token.do
    └── store token in keychain

Any tool call
    └── get_valid_token()
        ├── load token from keychain
        ├── token_is_expiring()?  # Within 60 seconds of expiry
        │   ├── No  → return access_token
        │   └── Yes → fetch_token() → return new access_token
```

### `fetch_token()`

POST to `/oauth_token.do` using Resource Owner Password Credential grant.

```
grant_type=password
&client_id=CLIENT_ID
&client_secret=CLIENT_SECRET
&username=nowlink.dev
&password=PASSWORD
```

Token is augmented with `created_at` (unix timestamp) before storing in keychain.

### `token_is_expiring()`

```python
def token_is_expiring(token_data: dict) -> bool:
    expires_at = token_data["created_at"] + token_data["expires_in"]
    return time.time() > (expires_at - 60)
```

60-second buffer — proactive refresh, never reactive.

## Module: `server.py`

### Tool: `ping`

**Description:** Check if NowLink is connected to ServiceNow and return the instance
details. Use this to verify the connection is working before running other tools.

**Parameters:** None

**Returns:**
```json
{
  "status": "connected",
  "instance": "https://dev123.service-now.com",
  "user": "nowlink.dev",
  "message": "NowLink is connected to https://dev123.service-now.com as nowlink.dev"
}
```

## ServiceNow Setup Requirements

### OAuth Application Registry

| Field | Value |
|-------|-------|
| Name | NowLink Dev |
| Grant type | Resource Owner Password Credential |
| Access token lifespan | 1800 seconds |
| Refresh token lifespan | 8,640,000 seconds |
| Client type | Integration as a Service |
| Allow access only to APIs in selected scope | **Unchecked** |

### Integration User

| Field | Value |
|-------|-------|
| User ID | `nowlink.dev` |
| Identity type | **Default (not Machine)** |
| Internal Integration User | **Unchecked** |
| Active | Checked |
| Roles | `rest_service` |

**Critical:** Machine identity type or Internal Integration User checked will silently
block OAuth password grant with `access_denied`. No useful error message is given.
