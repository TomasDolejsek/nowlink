# NowLink v0.1 — Technical Specification

**Version:** 0.1.0
**Built:** Week 1
**Status:** Complete
**Python:** 3.12+
**Platform:** Windows (tested), macOS (supported)

---

## Overview

v0.1 adds read capability: three MCP tools that let Claude query any ServiceNow table,
fetch individual records, and inspect table schemas. The core differentiator is
`shaper.py` — a data transformation layer that converts raw 40-80 field ServiceNow
responses into clean 8-12 field output that LLMs can reason about without hallucinating
field names or values.

## Module: `client.py`

Synchronous HTTP client wrapping the ServiceNow Table API. Uses `httpx`.

### Key design decisions

**`sysparm_display_value=all`** on every query. ServiceNow returns every field as
`{"display_value": "John Smith", "value": "abc123sys_id"}`. This makes reference
resolution trivial — the human-readable name is already in the response, no second
API call needed to resolve sys_ids.

**`sysparm_order_by_desc=sys_updated_on`** as default sort. Without this, ServiceNow
returns records in internal order that doesn't match any visible UI sort. Most-recently-
updated-first matches user expectations for natural language queries.

**Hard cap of 50 records** regardless of what the caller requests. Protects token budgets.

**Translated error messages** — 401, 403, 404, 429 all return readable errors instead
of raw ServiceNow JSON.

### Functions

| Function | Description |
|----------|-------------|
| `query_records(table, sysparm_query, fields, limit)` | Query a table, return raw records |
| `get_record_by_number(table, number)` | Fetch one record by display number (e.g. INC0001234) |
| `get_record_by_sys_id(table, sys_id)` | Fetch one record by sys_id |
| `describe_table(table)` | Return field metadata from `sys_dictionary` |

## Module: `shaper.py`

The core differentiator. Transforms raw ServiceNow API output into clean, token-efficient
dicts that LLMs can reason about correctly.

### Three responsibilities

**1. Field allowlists** — per-table lists of fields that matter. Incident returns 17
fields; the raw API returns 60+. Unknown tables fall back to pass-through minus
STRIP_ALWAYS fields, so NowLink works on custom tables without pre-configuration.

**2. Value mapping** — coded values translated to human labels:

| Field | Raw value | Shaped value |
|-------|-----------|--------------|
| priority | `"1"` | `"P1 - Critical"` |
| priority | `"2"` | `"P2 - High"` |
| state (incident) | `"1"` | `"New"` |
| state (incident) | `"6"` | `"Resolved"` |
| state (change) | `"-1"` | `"Implement"` |
| impact | `"1"` | `"High"` |

State maps are **per-table** — the same numeric code means different things on incident
vs problem vs change_request.

**3. Reference field resolution** — `{"display_value": "John Smith", "value": "abc123"}` 
becomes `"John Smith"`. Empty references are excluded entirely rather than returned as
empty strings.

### STRIP_ALWAYS fields

Always removed regardless of table: `sys_mod_count`, `sys_class_name`, `sys_tags`,
`sys_updated_by`, `sys_created_by`, `upon_approval`, `upon_reject`, and others.

### Tables with defined allowlists

`incident`, `problem`, `change_request`, `sc_request`, `sc_req_item`, `task`,
`sys_user`, `cmdb_ci`

## Module: `logger.py`

Writes one line per tool call to `~/.nowlink/logs/YYYY-MM-DD.log`.

Format: `HH:MM:SS | tool_name | params={...} | result=...`

Errors logged separately with `ERROR=` prefix. Log directory created automatically.

## MCP Tools

### `query`

**When to use:** User asks to find, list, search, or show multiple records from any table.

**Parameters:**
- `table` — ServiceNow table name (e.g. `incident`, `problem`, `change_request`)
- `filters` — Encoded ServiceNow query string (e.g. `priority=1^state=1`). Empty = most recent.
- `limit` — Records to return. Default 20, max 50.

**Returns:** `{table, count, records: [shaped_record, ...]}`

**Tool description includes:** common field names, state values (1=New, 6=Resolved),
priority values (1=Critical), and LIKE syntax for text search. This is what prevents
Claude from hallucinating filter syntax.

---

### `get_record`

**When to use:** User asks about a specific record by number or sys_id.

**Parameters:**
- `table` — ServiceNow table name
- `identifier` — Record number (e.g. `INC0001234`) or 32-char hex sys_id

**Identifier routing:** If `len(identifier) == 32` and all hex chars → `get_record_by_sys_id`.
Otherwise → `get_record_by_number`.

**Returns:** Single shaped record dict.

---

### `describe_table`

**When to use:** User asks what fields a table has, or Claude needs field names before
constructing a filter.

**Parameters:**
- `table` — ServiceNow table name

**Returns:** `{table, field_count, fields: [{field, label, type, mandatory?, references?}]}`

Mandatory fields sorted first. Capped at 30 fields.

**Known limitation:** Only returns fields defined directly on the table in `sys_dictionary`.
Inherited fields from parent tables (e.g. `task` fields on `incident`) are not included.
This is intentional — walking the full parent chain returns 200+ fields, defeating the
shaper's purpose. See `docs/decisions/v0.1-known-issues.md`.

## `cli.py` — Changes from v0.0

**`nowlink connect`** now auto-detects the venv executable path:

```python
executable = Path(sys.executable)
nowlink_exe = executable.parent / "nowlink.exe"  # Windows
```

No more hardcoded paths. Works on any machine after `pip install -e .`.

## Unit Tests

`tests/test_shaper.py` — 17 tests, all passing. Run with `pytest -v`.

| Test group | Count | What's covered |
|------------|-------|----------------|
| Priority mapping | 3 | P1, P2, P4 |
| State mapping | 4 | Incident (×2), problem, change_request |
| Reference resolution | 2 | Display name returned; empty field excluded |
| System field stripping | 1 | STRIP_ALWAYS fields removed |
| Allowlist filtering | 2 | Known table filtered; unknown table pass-through |
| List shaping | 2 | Multiple records; empty list |
| Schema shaping | 3 | Mandatory first; reference key; sys_id stripped |

Tests use a `dv()` helper that simulates `sysparm_display_value=all` field format
without making any HTTP calls.
